# 🌿 FitAura – Health & Wellness Companion

FitAura is a modern web-based health and wellness application designed to help users build better habits, track activities, and stay motivated through gamification.

---

## 🚀 Features

- 🏃 Activity Tracking – Monitor daily fitness activities  
- 🎯 Goal Setting – Set and achieve personal health goals  
- 🏆 Gamification – Earn rewards, badges, and stay motivated  
- 📊 Interactive UI – Clean and responsive user interface  
- ⚡ Fast Performance – Built using Vite  

---

## 🛠️ Tech Stack

- **Frontend:** HTML, CSS, JavaScript  
- **Build Tool:** Vite  
- **Runtime:** Node.js  

---

## 📂 Project Structure    

FitAura/
│── index.html # Main UI structure
│── style.css # Styling and layout
│── script.js # Core application logic
│── gamification.js # Reward system & gamification logic
│── package.json # Dependencies
│── package-lock.json # Dependency lock file
│── vite.config.ts # Vite configuration
│── tsconfig.json # TypeScript configuration
│── metadata.json # Project metadata
│── README.md # Documentation

This structure separates UI, logic, and configuration files, making the project easy to maintain and scalable.
